# Overlay Acceptance / 悬浮窗玻璃卡片风验收标准

## 1. 文档目的

本文件用于约束本轮悬浮窗（overlay）样式升级的工程边界与验收标准。

本轮目标是：
在不改变悬浮窗运行方式和业务逻辑的前提下，完成一次“深色玻璃卡片风”的轻量样式升级。

本文件优先级高于临时审美偏好。
如果某个视觉细节会影响稳定性、性能或可读性，应放弃该细节。

---

## 2. 本轮明确目标

本轮必须做到：

1. 悬浮窗整体观感比当前版本明显更高级
2. 有清晰的深色玻璃卡片风格
3. 正常模式层级更清楚
4. mini 模式保持轻量
5. 长时间运行时不出现明显性能问题
6. 不影响脚本稳定性
7. 不影响已有业务逻辑与状态语义

---

## 3. 技术边界

本轮技术边界固定如下：

1. 保留当前 Tk 技术栈
2. 不切换到 PySide6
3. 不新增大体量第三方 UI 依赖
4. 不引入真实背景模糊
5. 不做 Python 侧实时高斯模糊
6. 不做连续动画
7. 不改悬浮窗主线程 / 子线程组织方式
8. 不改当前刷新节奏
9. 不改当前字段来源
10. 不改 F12、暂停、恢复、mini / normal 切换链路

---

## 4. 明确不允许改动的范围

本轮默认不允许改动以下方向：

1. 主抢购循环逻辑
2. 线程 2 / 3 / 5 / 6 / 7 / 14 / 15 已合回主线逻辑
3. 数据库结构
4. round_persistence 业务含义
5. main.py 主调度逻辑
6. switch.py 换区 / 换号 / 失败治理逻辑
7. purchase.py 抢购策略逻辑
8. 网页逻辑
9. 远端镜像逻辑
10. 本机配置外置规则

如果实现样式时发现必须动到以上内容，应先停下汇报，不得顺手改。

---

## 5. 允许改动的范围

本轮允许优先改动：

1. `overlay.py` 显示层样式
2. 与悬浮窗纯显示相关的轻量辅助函数
3. 与显示层布局、颜色、分组、静态视觉样式直接相关的局部实现

要求：

- 必须保持最小改动面
- 不得借机重构整个 overlay 系统

---

## 6. 性能验收标准

本轮必须满足：

1. 样式升级后，不应出现明显的 CPU 持续拉高
2. 样式升级后，不应引入明显卡顿
3. 样式升级后，不应出现明显闪烁
4. 样式升级后，不应出现明显拖慢主脚本响应
5. 样式升级后，不应因额外动画、阴影、模糊导致占用异常

红线：

- 不允许为了玻璃质感引入高成本实时绘制
- 不允许为了玻璃质感牺牲长时间挂机稳定性

---

## 7. 可读性验收标准

本轮必须满足：

1. 关键数值比当前版本更清晰
2. 可运行时间必须更醒目
3. 余额、道具库存必须一眼能找到
4. 上架成功 / 抢购成功 / 抢购失败三项更整齐
5. 文本不能因为透明底而发虚
6. 颜色不能因为装饰而降低辨识度
7. normal 模式必须比当前更有层级
8. mini 模式必须保持简洁，不得臃肿

---

## 8. 稳定性验收标准

本轮必须满足：

1. 不得新增新的闪退点
2. 不得新增新的线程竞争风险
3. 不得新增新的热键相关风险
4. 不得新增新的显示切换异常
5. 不得破坏暂停 / 恢复 / mini / normal 的现有行为
6. 不得导致长时间运行后悬浮窗明显失常

---

## 9. 审美验收标准

本轮期望达到以下效果：

1. 主面板像深色玻璃卡片，而不是普通纯色面板
2. 有轻微亮边和高光层次
3. 内容分区像高级工具面板，而不是文字堆叠
4. 子卡片分组自然，不生硬
5. 整体高级、克制、冷静
6. 不出现电竞风、霓虹风、花哨动画风

---

## 10. mini 模式专项验收

mini 模式单独要求：

1. 保持小而稳
2. 保持信息最少但关键
3. 可有轻微玻璃感
4. 不应复制 normal 模式全部细节
5. 不应因追求设计感而降低辨识速度

---

## 11. 实施顺序要求

Codex 实施时建议按以下顺序推进：

1. 先收结构
2. 再收层级
3. 再收边框 / 高光 / 玻璃质感
4. 最后做配色微调

禁止倒过来：
不能先堆视觉装饰，再回头补结构。

---

## 12. 验收输出要求

Codex 完成后，验收说明必须至少回答：

1. 本次实际改了哪些文件
2. 哪些逻辑明确未动
3. normal 模式改了什么
4. mini 模式改了什么
5. 如何保证没有引入真实模糊和连续动画
6. 如何控制了性能风险
7. 需要人工重点实机观察的点有哪些

---

## 13. 最终原则

如果“更像玻璃”和“更稳更清楚”发生冲突，固定以：

**更稳、更清楚、更轻量** 优先。

本项目的悬浮窗首先是长期挂机工具面板，其次才是设计对象。
