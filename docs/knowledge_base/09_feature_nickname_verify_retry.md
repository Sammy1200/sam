# 昵称模板校验重试

这份文档用于说明当前昵称模板校验区域，以及昵称未匹配后的重试口径。

## 识别区域

当前默认昵称模板识别区域为：

- `1415,600 -> 1480,630`

说明：

- 这是默认值，落在 `config.py`
- 如果本机真实 `local_switch_account_config.json` 单独配置了 `nickname_verify_region`，则本机配置优先
- 当前 live 配置未单配该字段时，会直接使用这组默认区域

## 昵称未匹配后的处理

当前口径已经改为：

1. 先做一次正常昵称模板校验
2. 如果未匹配到：
   - 重新登录该执行位所属账号
   - 重新打开大区列表
   - 重新选择该执行位对应大区
   - 再做昵称模板校验
3. 总共额外重试 `2` 次
4. `2` 次后仍失败，才进入原有微信推送与暂停出口

## 适用范围

这次口径同时覆盖：

- 线程 6 的正常换号/换区昵称校验
- 边界换号、同账号跨区、临时模式定向切换中的昵称校验
- 启动页上架模式进入目标执行位时的昵称校验

## 没有改什么

这次没有修改：

- 抢购主循环结构
- 换号后的进场顺序
- 大区坐标
- 昵称模板目录读取优先级
- 昵称匹配阈值默认值
