# 术语表

这份文档用于统一项目里的高频术语，避免不同文档、不同人、不同 AI 把同一个词说成不同意思。

## canonical

当前系统里的主事实层，特指 canonical SQLite 及其 `account_stats` 真源记录。它是唯一真实数据源。

## runtime snapshot

当前运行进程的辅助快照，主要指 `thread6_runtime.sqlite3` 里记录的执行位、昵称、大区索引等运行时信息。它不是 canonical。

## baseline_item_count

当前账号的道具库存基线字段，存储在 canonical 中。网页最小修改允许直接改这个字段。

## 当前账号本轮

当前账号在本次进入“预上架 -> 抢购 -> 结束写回”链路期间产生的一轮运行过程，不等于整机全部历史。

## 可运行时间

从网页和诊断视角看到的“当前账号还剩多少正式抢购活跃时间”。它是基于 2 小时 45 分规则推导出的派生值。

## 冷却剩余时间

当前账号距离解除 `账号限制` / `抢购时长已到` 状态还剩多少时间。它是派生字段，不是单独主存字段。

## 轻量落库

运行中不做整轮收尾时，对最小必要字段做的同步写入。当前主线要求保留 56 分钟轻量落库节奏。

## 最终写回

当前账号结束本轮后，把该轮结果正式写回 canonical 的收尾动作。它会更新轮次字段、状态字段和关键时间字段。

## 远端镜像

保存在 `remote_sync_mirror.sqlite3` 中的远端账号快照副本，用于展示和汇总，不是真源。

## 公网快照

对外展示的网页快照视图。它的职责是展示和参考，不承担真源判定和正式写入口职责。

## 本机真实配置

当前机器实际运行所使用的 JSON 配置和模板资源，例如 `local_switch_account_config.json`、`local_web_sync_config.json`、本机昵称模板目录。

## 示例配置

只用于说明字段结构和格式的样例文件，不代表当前机器真实运行值，也不能覆盖真实配置。

## live 数据

当前机器真正参与运行的数据库、配置和模板资源。当前统一优先从 `C:\py666` 读取。

## 执行位

当前系统用于调度账号 / 大区链路的位置编号。它用于流程路由和启动器识别，但不是 canonical 主键。

## runtime window

当前账号的运行窗口锚点与滚动窗口状态，用于计算 2 小时 45 分剩余时间和 24 小时窗口滚动。

## 已准备

当前正式状态值之一，表示账号已恢复到可重新进入正常链路的准备态。它是真值，不是展示映射。
