# 网页与同步边界

本文用于收口网页查看能力、最小修改能力、本地网页服务拉起方式，以及双机网页汇总的当前边界。

---

# 网页查看与最小修改能力

当前主线已经具备：
- 网页查看能力
- 单账号最小修改能力

这里的“最小修改”应理解为：
- 以低风险、最小范围为原则的局部网页侧修改
- 不改变主线真源规则
- 不引入双向同步语义

当前网页最小修改只允许以下 3 个字段：
- 道具数量（实际写入 `baseline_item_count`）
- 账号状态（`round_status`）
- 余额（`current_balance`，页面按“万”为单位输入和展示）

当前网页支持 `石头库 / 饰品库` 切换：
- 石头库对应 `C:\py666\account_stats.sqlite3`，页面显示 `道具库存`、`余额（万）`
- 饰品库对应 `C:\py666\accessory_account_stats.sqlite3`，页面显示 `饰品库存`、`金币（万）`
- 本机查看页切到哪个库就保存到哪个库；保存字段、校验规则和回读确认沿用同一套逻辑
- `账号状态`、`可运行时间`、`冷却剩余时间` 是两库通用数据；网页或脚本在任意一边修改后，会同步到底层另一边的 `round_status`、`purchase_running_seconds`、`runtime_window_start_time`、`last_limit_time`
- 库存、余额/金币、抢购数、上架数仍按库隔离：石头库保存石头数据，饰品库保存饰品数据，不能互相覆盖

其中账号状态的当前口径必须写清：
- `已准备` 是新的正式状态值，不是显示映射
- `已准备` 会真实写入 SQLite 真源，并出现在网页状态下拉中
- 当当前状态为 `账号限制` 或 `抢购时长已到`，且冷却剩余时间 <= 0 时，会自动恢复为 `已准备`
- 当网页手动把状态改成 `已准备` 时，可运行时间恢复为 2 小时 40 分，且冷却剩余时间 = 0

不允许通过网页最小修改直接改动：
- 抢购主循环依赖的运行时关键参数
- SQLite 真源统计口径
- 会影响跨机汇总主键判断的昵称主键语义

补充：临时抢购模式的 `临时号` 来自 `thread6_runtime.sqlite3` 辅助快照，不写入 canonical 单账号主表。查看页本机栏目和公网页对应电脑 Snapshot 栏目可以展示该行，但该行只读；账号状态按正常账号状态口径展示，并保留到下一次临时模式启动覆盖。

不要把它表述成：
- 全量网页编辑后台
- 任意远端数据治理入口
- 跨机共享写入口

- 不代表网页服务脱离主入口独立成为新的正式启动链路

# 公网快照与历史写回口径

当前正式口径必须区分 3 层：

- 本机网页：
  - 用于查看 canonical 真源
  - 允许本机单账号最小修改
- 远端镜像：
  - 用于展示远端最近快照
  - 不是真源
- 公网快照：
  - 只用于查看
  - 只开放“刷新按钮”
  - 不开放任何其他修改能力
  - 远端快照区块按 `expected_remote_machines` 与已收到的镜像数据全部展示，不只固定展示某一台电脑；当前 1 号电脑预置显示 2/3/4 号电脑
  - 查看页与公网页的快照刷新按钮刷新后应尽量恢复原滚动位置，避免页面回到顶部

历史口径说明：
- 线程 14 第一阶段历史上曾讨论并落到“远端最小写回”设计与部分代码结构
- 但它不属于当前正式公网能力
- 当前对外口径一律按“公网只查看 + 刷新按钮”理解

# 远端镜像边界

当前远端镜像规则：
- 远端镜像不是真源
- SQLite 仍是唯一真实数据源

具体边界如下：
- 远端页面可以查看镜像结果，但不能替代本机 SQLite 作最终判定
- 远端镜像可以承接展示、副本汇总、只读查询，但不能作为最终写入口
- 远端镜像本身不能直接回写本机真实账号库
- 远端镜像不能覆盖本机轮次统计、轻量落库或最终写回结果
- 出现镜像与本机不一致时，以本机 SQLite 真源为准
- 当前公网快照只允许手动刷新镜像，不允许提交任何修改
- 远端镜像按 `db_mode` 区分石头库和饰品库，同一机器的两个库快照互不覆盖

因此文档中必须避免以下错误表述：
- 公网可最小写回
- 公网可修改远端账号
- 远端可直接改真源
- 镜像库与本地库地位等同
- 远端页面可作为最终写入来源

---

# 明确不做的事项

当前边界内，明确不做以下能力：
- 双向同步
- 共享同一个 SQLite 文件
- 公网除刷新按钮外的任何修改
- 远端直接绕过专用接口修改本机主账号数据
- 远端覆盖本机统计与持久化结果

补充：这里的“不做双向同步”指不做跨机器、跨公网的双向写回；本机石头库与饰品库之间仅允许同步账号状态、可运行时间、冷却剩余时间这三类通用字段。

如果后续有新需求，也必须在不破坏以下硬规则的前提下单独评估：
- SQLite 是唯一真实数据源
- 昵称是唯一键
- 远端镜像不是真源
- 不影响抢购主循环
